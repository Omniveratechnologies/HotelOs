**Reception Dashboard Workflow** 

The Reception Dashboard is the central control panel for hotel staff. It allows the receptionist to  manage room occupancy, guest check-in/check-out, monitor service requests, and track food orders  in real time. 

![alt text](image.png)

**1\. Reception Dashboard Overview**   
When the receptionist logs in, the dashboard displays: 

• Occupied Rooms   
• Available Rooms   
• Total Rooms   
• Pending Service Requests   
• Active Food Orders   
These statistics provide a quick overview of the hotel's current status. 

**2\. Room Management** 

The Room Grid displays the status of every room. 

**Room Status**

| Status  | Description |
| ----- | ----- |
| **Available**  | Room is vacant and ready for check-in. |
| **Occupied**  | A guest is currently staying in the room. |
| **Reserved**  | Room has been booked but the guest has not yet checked in. |
| **Needs   Cleaning** | Guest has checked out and housekeeping is required before the room can be  assigned again. |

**3\. Guest Check-in Process** 

**Step 1 – Select Room** 

• Receptionist clicks on an **Available** room. 

**Step 2 – Check-in Form Opens** 

The receptionist enters the guest details: 

• Guest Name   
• Phone Number   
• Number of Guests   
• Number of Nights   
• ID Proof (Aadhaar/Passport) 

**Step 3 – Confirm Check-in** 

The receptionist clicks **Confirm Check-in**. 

**System Actions** 

• Room status changes from **Available** to **Occupied**.   
• Guest information is saved.   
• Guest Tablet for that room is activated.   
• Occupied Room count increases.   
• Available Room count decreases.

**4\. Guest Check-out Process** 

**Step 1** 

Receptionist selects an **Occupied** room. 

**Step 2** 

System displays guest details and pending services. 

**Step 3** 

Reception verifies: 

• Food Bills   
• Amenity Charges   
• Pending Payments   
• Additional Charges 

**Step 4** 

Reception clicks **Check-out**. 

**System Actions** 

• Room status changes to **Needs Cleaning**. • Guest session ends. 

• Guest dashboard is deactivated.   
• Final bill is generated.   
• Housekeeping is notified.

**5\. Service Request Management** 

The Service Requests panel displays all guest requests, such as: 

• Amenity Requests   
• Housekeeping Requests   
• Restaurant Call Requests   
Each request includes: 

• Room Number   
• Request Type   
• Request Details   
• Current Status 

**Reception Action** 

Click **Acknowledge** to confirm that the request has been received. 

**System Actions**  
• Request status changes from **Requested** to **Acknowledged**. • Relevant department is notified: 

◦ Housekeeping   
◦ Restaurant   
◦ Guest Services

**6\. Live Food Order Monitoring** 

Reception can monitor every food order placed by guests. The dashboard displays: 

• Room Number   
• Ordered Items   
• Payment Method   
• Current Order Status   
Example statuses: 

• New   
• Preparing   
• Ready   
• Out for Delivery   
• Delivered

**7\. Dashboard Statistics** 

The top summary cards update automatically whenever there is a change. 

| Card  | Updates When |
| ----- | ----- |
| Occupied Rooms  | Guest checks in or checks out |
| Available Rooms  | Room becomes vacant or occupied |
| Total Rooms  | Fixed hotel room count |
| Pending Requests  | New guest service requests are  received |
| Active Food   Orders  | A food order is placed or completed |

**8\. Real-Time Synchronization** 

Every action performed on any dashboard is synchronized instantly across the system. **Guest Dashboard** 

• Displays room status, food order status, and service request updates. **Kitchen Dashboard** 

• Receives new food orders and updates preparation and delivery status. **Reception Dashboard** 

• Tracks room occupancy, service requests, and live food order progress. **Complete Reception Workflow**
